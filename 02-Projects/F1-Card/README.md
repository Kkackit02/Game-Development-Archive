# F1 Card (F1 카드 그랑프리)

Jack's Bean 팀에서 개발한 F1 테마의 카드 게임 프로젝트입니다.

---

## 🎮 프로젝트 개요

- **엔진:** Unity
- **언어:** C#
- **장르:** 카드 게임 / 전략
- **개발 참여:** 정근녕 (클라이언트 프로그래밍)
